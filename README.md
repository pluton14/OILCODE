# НефтеКод — мультиагентная система управления производством ДТ

Рекомендательная система для оператора: смотрит на состояние процесса
АВТ → гидроочистка → блендинг, оценивает риск выхода за спецификацию и риск
для оборудования, предлагает безопасное изменение режима — или обоснованно
отказывается, если надёжного варианта нет.

## Запуск

```bash
pip install -r requirements.txt
python run_demo.py
```

Первый запуск разбирает xlsx и кладёт результат в `cache/` — это занимает
около минуты. Дальше быстро. Чтобы пересобрать — удалить папку `cache/`.

Другие сценарии:

```bash
python run_demo.py --scenario stale
python run_demo.py --timestamp "2024-06-15 12:00"
```

## Как мы работаем

Цепочка собрана целиком **с первого дня**: `run_demo.py` уже проходит путь от
сырых данных до готовой рекомендации. Внутри агентов пока baseline-заглушки.

Задача каждого — заменить свою заглушку на настоящую реализацию, **не меняя
контракт**. Тогда система не ломается у соседа и в любой момент её можно
показать целиком. Ноутбуки для исследования — в `notebooks/`, в `oilcode/`
попадает только то, что работает.

Что делать в каждом агенте — написано в его docstring, блок «ЧТО ДЕЛАТЬ ДАЛЬШЕ».

## Жёсткие правила

1. **Спецификация — к товарному продукту ПОСЛЕ блендинга**, а не к выходу
   гидроочистки: сера ≤ 10 мг/кг, Т95 ≤ 360 °C, цетановое число ≥ 51.
   Превышение серы на выходе ГО само по себе не авария.
2. **Цель — минимальная стоимость, а не минимум серы.** Глубокое
   обессеривание стоит энергии. Переочистка — убыток, а не заслуга.
3. **Никакой информации из будущего.** Метка ЛИМС — момент отбора пробы,
   результат доступен на 4 часа позже. Синхронизация только назад по времени.
4. **Смысл тега не берём из буквы кода.** Но и справочник КИП по 24-2000
   данным противоречит (17 кодов из 26) — вопрос организаторам открыт.
   Обращаться к тегам только через `config.tag_key()`.
5. **Каждое допущение помечается как допущение.** Исторический min/max — не
   промышленный предел.
6. **Отказ — валидный ответ.** Если данных мало или все варианты нарушают
   ограничения, система обязана сказать это, а не выдумать рекомендацию.
