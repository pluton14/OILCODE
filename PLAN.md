## Что внутри каждого компонента

| Компонент | Метод | Почему |
|---|---|---|
| Агент данных | правила | отказы известны поимённо: 307, 251, остановки, залипания |
| Оценка серы 0–3 ч | инерция + поправка на действие | проверено: инерция бьёт ML (−33 % на 1 ч) |
| Эффект изменения режима | физика, калиброванная | из истории не восстанавливается, установка под управлением |
| Виртуальный анализатор серы | градиентный бустинг | нужен, когда ПАК молчит (+7 % к медиане) |
| Агент надёжности | тренд WABT до предела | отраслевой стандарт End-of-Run prediction |
| Оптимизация | перебор по сетке | прозрачно |
| Блендинг | линейное программирование | задача линейна |
| Оркестратор | детерминированные правила | обязан быть воспроизводимым |

**Позиционирование:** ценность не в предсказании серы (там нас бьёт инерция), а
в принятии решения. Говорим это сами.

## Как проверяем, что работает

Данные **не размечены**. Поэтому разделяем:

| Что проверяем | На чём | Порог |
|---|---|---|
| Точность прогноза | настоящие метки ЛИМС (1462 по сере, 1292 по Т95) | лучше трёх баз: медиана, **инерция**, ВАК |
| Предупреждение о риске | **наше определение** события + порог | recall ≥ 70 %, precision ≥ 40 % |
| Устойчивость к порогу | те же метрики при 4 порогах | выводы не переворачиваются |
| Ложные срабатывания | спокойный период | ≤ 10 % вмешательств |
| Инварианты | не нужны метки | **ровно 0 нарушений** |

Инварианты: не выводим за спецификацию, доли = 100 %, присадка ≤ 3 %, ничего из
будущего, при непригодных данных отказ, вето не обходится, два прогона дают
одинаковые числа.

**Не проверяем и говорим об этом сами:** помогла бы рекомендация (действий не
было в истории); совпадают ли решения с оператором (**нет тегов уставок и
журнала действий**); верны ли границы Т95 и цетана (спецификацию не выдали).

**Метрика пишется раньше модели** — иначе «улучшили» непроверяемо.
